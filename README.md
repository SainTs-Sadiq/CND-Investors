# The CND Investors

Educational/demo website prototype for a fictional digital-asset investment-management company.

## Pages
- `index.html` — public marketing site, plan cards and illustrative calculator.
- `client.html` — demo client portal using browser `localStorage` only.
- `admin.html` — demo administration dashboard using the same local demo store.
- `styles.css` — shared responsive styling.
- `app.js` — demo state, authentication and UI logic.

## Important
This repository intentionally does **not** connect to a payment processor, blockchain wallet, custody provider, bank account, or real investment backend. All balances, users, investment values and withdrawal requests are simulated locally for software demonstration and educational use.

Before any real financial deployment, replace the demo state with a secure server-side architecture and obtain appropriate legal, regulatory, KYC/AML, custody, security and financial compliance review.
